# Vendored DashUIKit

`Sources/DashUIMac/DashUIKit/` is a macOS port of **DashUIKit** (`dashpay/DashUIKit`), the SwiftUI design
system the Dash iOS wallet uses (research 03 §3.5, DESIGN-opus §1.10).

| | |
|---|---|
| Upstream | `dashpay/DashUIKit` (read from the fork `PastaPastaPasta/DashUIKit`) |
| Revision | `e8d92434bfc28fbf933b896cd40a01dd61835b5f` (`e8d9243`) |
| Local copy of that revision | `/Users/pasta/workspace/dashwallet-desktop-deps/dashuikit-src/` (tarball + unpacked tree) |
| License | MIT, per-file headers (kept on every vendored file) |
| Module | compiled into `DashUIMac`; macOS only (`#if os(macOS)` in every file) |

DESIGN-opus §1.10 plans an upstream PR that adds `.macOS(.v14)` to DashUIKit with AppKit ports of
`Toast`, `SearchBar` and `AddressFieldView`. Until it merges, the components live here so the macOS app does
not depend on an unmerged branch. When it merges, replace this directory with the package dependency and
keep only the desktop-specific changes listed below that upstream did not take.

## What was copied

Every Swift file under upstream `Sources/DashUIKit/`, at the same relative path, except:

| Upstream file | Why it is not here |
|---|---|
| `Foundation/BundleToken.swift` | Resources come from `DashUIMac`'s own bundle (`DashIconLibrary.bundled`). |
| `Foundation/DashTextStyle.swift` | Replaced by `DesignTokens.DashTextStyle` (same names, sizes, weights, line heights). |
| `Resources/Media.xcassets` | Colours come from `DesignTokens` (`DashColor`, generated by `scripts/gen-tokens.swift`); icons from the exported set in `Resources/Icons` (symlinked as `Sources/DashUIMac/Resources/Icons`). |
| `Table List/` | Copied as `TableList/` (no space in the directory name). |

## Changes made in every file

- `#Preview` / `PreviewProvider` blocks removed (the gallery in `Gallery/DashUIMacGallery.swift` replaces them
  and is snapshot-tested).
- Wrapped in `#if os(macOS)`.
- A header line `Vendored from DashUIKit e8d9243 (<path>)` followed by a `Changes:` note describing
  file-specific edits. That note is the authoritative per-file record; the summary below groups them.

## File-specific changes (summary)

| Area | Change |
|---|---|
| Colours (`Color+DashUI.swift`) | Every token resolves from `DesignTokens.DashColor` instead of a colour set. `purple` is dropped (DesignTokens excludes it; no purple in the desktop palette). `shadow` is a dynamic `NSColor`. |
| Type (`Font+DashUI.swift`, `LineHeight+DashUI.swift`) | `.dashFont(_:)` and `Font.dash.*` read `DesignTokens.DashTextStyle`; only the AppKit line-height branch is kept. |
| Icons (`Icon_DashUI.swift`, `Image+DashUI.swift`) | Each case maps to a `DashIconToken` from the exported icon set. `.uiImage` becomes `.nsImage`; a `.token` case is added; `DashIconImage` picks the light or dark file from the environment. Cases with no exported icon are dropped: the third-party service, integration and brand icons of the iOS Menu/Explore screens (for example `coinbase`, `uphold`, `crowdnode`, `topper`, `maya`, `ctx`, `piggyCards`, `zenledger`, `applePay`, `gPay`, `paypal`, `faceID`, `staking`, `atm`) and `illustrationXmark` (see Illustrations). |
| `Toast` | The UIKit `UIVisualEffectView` blur becomes a dark `.ultraThinMaterial`. |
| `SearchBar` | One focus-driven implementation (iOS 14 fallback removed); plain text-field style; Escape clears and leaves the field; 24 pt clear button. |
| `AddressFieldView` | One `TextField(axis: .vertical)` path; plain text-field style; iOS-only autocapitalisation dropped; plain button style on the QR and clear buttons. |
| `BottomSheet` | Chrome for a macOS `.sheet`: no grabber, no detents, no `NavigationView`; dismissal through `\.dismiss` and Escape. `selfSizingSheet(...)` and `BottomSheetHeightPreferenceKey` are not ported. |
| `DashSwitch`, `MenuItem` | System switch toggle style (macOS defaults to a checkbox), tinted with `switchTrackFillOn`; accessibility labels for the hidden visible label. |
| `DashButton` | Icons through `DashIconImage`; small-control spinner (the macOS default is 32 pt). |
| `SwapAmountView` | Long-press paste becomes a right-click "Paste" context menu. |
| `ErrorIllustration` | The missing `illustration-xmark` asset is drawn with `XmarkIcon`. |
| `LoadingIllustration` | The spinner is driven without Combine (Combine is banned in shared code, DESIGN-opus §1.11). |
| `SystemMessageView` | `DashUIKit.DashButton` is qualified as `DashUIMac.DashButton`. |

## Desktop components (not vendored)

`Desktop/` holds components DashUIKit does not have, built on the same tokens: `AmountField`, `Badge`,
`BalanceHeader`, `DataTable`, `PassphraseField`, `QRView`, `SidebarRow`, `StatusBar`, `TransactionRow`. They are
ours; no upstream sync applies.

## Updating

1. Unpack the new upstream revision next to the current one in `dashwallet-desktop-deps/dashuikit-src/`.
2. `diff -ru` the old and new upstream trees; apply each upstream change to the matching file here, keeping the
   changes listed above.
3. Update the revision in this file and in each touched file's `Vendored from` line.
4. Re-run `scripts/gen-tokens.swift` if colour sets, the type scale or icons changed, then
   `swift test --filter "DashUIMacSnapshotTests|DesignTokensTests"`; re-record snapshots
   (`DWD_RECORD_SNAPSHOTS=1`) only for intended visual changes and review the PNG diffs.
