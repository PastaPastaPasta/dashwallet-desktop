# Glossary

These terms mean the same thing on every screen and in every language. Translators keep the
**fixed** terms exactly as written, in Latin script. They translate the others, but always with the
same word, and they note that word here under the language's section when the catalog is added.

| Term | Fixed | Meaning |
|---|---|---|
| Dash | yes | The cryptocurrency and its network. Never translated, never inflected. |
| DASH, mDASH, μDASH, duffs | yes | Units of Dash: 1 DASH = 1,000 mDASH = 1,000,000 μDASH = 100,000,000 duffs. |
| DashPay Desktop | yes | This app's name. |
| DashPay | yes | Dash's social layer: usernames, contacts and payments to contacts. |
| CoinJoin | yes | Dash's coin mixing, which makes a wallet's coins harder to trace. |
| InstantSend | yes | Dash's near-instant, locked confirmation of a payment. |
| Platform | yes | Dash Platform, the network layer that holds identities, usernames and credits. |
| Shielded | yes | The private pool of Platform funds and its payments. |
| Mainnet, Testnet | no | The real Dash network, and the test network whose coins have no value. |
| masternode | no | A server that holds 1,000 DASH as collateral and serves the network; it votes on proposals. |
| evonode | no | A masternode that also serves Platform; it holds 4,000 DASH. |
| username | no | A DashPay name such as @alice, registered on Platform. |
| identity | no | The Platform record a username and credits belong to. |
| credits | no | Platform's unit of account, bought with DASH, that pays Platform fees. |
| contact | no | Another DashPay user that you and they have both accepted. |
| recovery phrase | no | The 12 or 24 words that restore a wallet. Never "seed", "mnemonic" or "backup words". |
| passphrase | no | What unlocks this app's wallet file. Not a PIN, not the recovery phrase. |
| proposal | no | A governance request for funds from the budget, voted on by masternodes. |
| superblock | no | The block that pays the budget proposals that passed. |
| watch-only | no | A wallet that sees its coins but holds no keys to spend them. |
| lock, unlock | no | Closing and opening the wallet's keys with the passphrase. |
