Service update and revocation

Your operator signs these with the operator key, which stays on their server. Dash Wallet doesn't hold that key, so it can't send them.

Bring a banned masternode back
The operator fixes the server, then sends a service update (protx update_service) from the node.
Stop the operator
The operator can revoke its key (protx revoke). You can also replace the operator yourself: change the operator key in Change keys or payout. The masternode then waits for the new operator's service update.
End the masternode
Spend the collateral. The masternode leaves the list at once. Use Release collateral in this masternode's More menu.
